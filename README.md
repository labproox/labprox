# Lab ProX

Windows software for medical laboratories. Lab ProX keeps patients, tests, results, bills, and PDF reports on the laboratory computer, with an optional Google Drive backup if that PC is lost.

Patient records stay on that computer. Lab ProX does not run a cloud database of those records.
